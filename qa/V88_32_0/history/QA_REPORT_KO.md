## 시험 방법과 미완료 범위

Chromium의 메모리 문서에 실제 HTML/CSS/JS를 렌더링했습니다. 업무 API·계정·매출은 가상 데이터이며 외부 네트워크는 차단했습니다. 원래 있던 jsdom 검사 숫자를 재사용하지 않았습니다.

네이티브 인쇄 PDF는 실제 렌더링입니다. **html2pdf의 실제 PDF 다운로드 엔진은 모의 객체로 대체해 취소·상태 복구·저장 보호 흐름만 시험했습니다.** 엔진 패키지를 내려받지 못해 기존 외부 의존성을 유지했으며, 의존성 업데이트·실제 다운로드 렌더링·CDN 성공을 주장하지 않습니다.

임시 로컬 호스팅의 서비스워커 실동작 검사는 브라우저의 `ERR_BLOCKED_BY_ADMINISTRATOR`로 진입 단계에서 중단됐습니다. 실제 서비스워커 검증 통과는 0개이고 별도 환경 제한으로 기록했습니다. 기존 서비스워커 코드의 버전/목록/해시 정적 검사와 배포 방어 회귀시험은 통과했습니다.

실제 Apps Script 응답/권한/재고/동시성/서버 인보이스 대장/메일/수금, GitHub 클라우드 배포, 운영 도메인 라우팅, 차트 CDN, iOS/Android 실기기와 네이티브 앱은 검증하지 않았습니다. 백엔드 소스는 포함되어 있지 않습니다. 운영 데이터 변경·배포도 하지 않았습니다.

기존 계약 요율·세무 정책·은행정보의 적정성을 검토한 것이 아닙니다. 입력 검증과 표시/계산 보호를 강화했으며 전체 운영 오류 부재를 보증하지 않습니다.
