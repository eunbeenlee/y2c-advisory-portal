## 추가한 안전장치 및 시험

조회 취소/새 요청 교체/늦은 응답, 조회 중 원본 변경, 이전 문서 Ctrl+P 인쇄, 서버 실패·잘못된 응답·집계 불일치, 날짜 역전, 선택값 변경, 월 자료 누락 경고, 언어 전환, PDF 중복 클릭·취소·시간 초과·재시도·변경된 원본 저장 차단, 임시 문서/렌더러 오버레이 정리, 저장을 이미 시작한 후 취소 거부를 검사했습니다.

인보이스는 360·390·768·1024·1100·1280·1440px에서 페이지 전체 가로 넘침을 검사했습니다. 다른 주요 5개 화면은 390·1440px에서 기본 배치, 포착된 JavaScript 예외, 의도하지 않은 업무 쓰기 요청을 검사했습니다. 관리 화면 탭 및 레시피 열기/닫기도 실행했습니다. 이 범위를 넘어 전체 업무 기능을 실거래로 시험했다는 뜻은 아닙니다.

## 시험 방식과 제한

실제 Chromium에 소스 HTML/CSS/JS를 메모리 문서로 렌더링했으며, 계정·API·매출은 가상 데이터로 대체했습니다. 네트워크는 차단했습니다. 화면·이벤트·네이티브 인쇄는 실제 브라우저 실행 결과입니다. 인증·응답 처리 코드는 별도의 실제 소스 단위시험으로 검사했습니다.

**네이티브 인쇄 PDF는 실제 생성 검증입니다. 외부 html2pdf 엔진을 사용하는 ‘PDF 다운로드’는 모의 렌더러로 제어 흐름을 검증한 것이며, 실제 외부 엔진의 이미지 렌더링·CDN 로딩은 미검증입니다.**

실제 서버 권한/재고/동시성/메일/수금, 호스팅 라우팅·서비스워커, 차트 CDN, 실기기 앱, GitHub 클라우드 배포는 검증하지 않았습니다. 서버 소스가 포함되어 있지 않으며 운영 데이터는 변경하지 않았습니다. 이전 버전의 jsdom 시나리오 수치를 이번 시험 결과에 재사용하지 않았습니다.
