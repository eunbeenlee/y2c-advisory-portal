포털 열기 / Open portal

iPhone · iPad

  1. 이 페이지를 Safari에서 여세요. / Open this page in Safari.
  2. 공유 → 홈 화면에 추가를 선택하세요. / Share → Add to Home Screen.
  3. ‘웹 앱으로 열기’ 옵션이 있으면 켠 뒤 추가를 누르세요. / Enable Open as Web App if shown, then Add.

홈 화면 아이콘으로 실행한 뒤 업무 계정으로 로그인하세요. / Launch from the home screen and sign in.

Android · Galaxy Fold — APK 설치

설치 파일을 다운로드해 실행하세요. / Download and open the APK installation file.

다운로드한 파일 → 설치. 요청되면 현재 브라우저의 앱 설치 허용을 켜주세요. iPhone에서는 APK를 설치할 수 없습니다. / Open the downloaded file and allow installation from your browser if requested. APK is Android only.

최신 Chrome 설치를 권장합니다. 웹사이트 연결 확인 전에는 주소창이 보일 수 있습니다. / Use an up-to-date Chrome browser. The address bar may remain until website verification completes.

  1. 이 페이지를 Chrome 또는 Samsung Internet에서 여세요. / Open in Chrome or Samsung Internet.
